# Argonaut Legacy

Настольная фантазийная консоль. Игру пишут на **TPython** — внутри того же окна, где она запускается. Отдельной браузерной версии нет и не планируется.

Код, спрайты, карта, музыка и эффекты живут в кассете `.alc`. Снаружи консоли править игру не нужно.

## Что внутри

| Клавиша | Редактор |
| --- | --- |
| F2 | Код на TPython |
| F3 | Спрайты, 128×128, цвет 0 прозрачный |
| F4 | Карта 128×32 тайлов |
| F5 | Музыка, паттерн 32×8 |
| F6 | Эффекты `sfx(0)` … `sfx(7)` |
| Ctrl+R | Пуск |
| Esc | Стоп, назад в редактор |
| F1 | Справка |

В игре стрелки или WASD ходят, Z и X — кнопки. A всегда влево, D всегда вправо.

Кассета по умолчанию — «Паром Тота»: лодка собирает огни на реке. Она лежит в `carts/ferry.alc`.

## Железо, которое консоль притворяется

- **THOTH** — 32-битный RISC, 20 МГц. Не совместим с ARM, только похож бюджетом тактов.
- Кадр 60 Гц стоит 333333 такта, каждый третий кадр — 333334. В среднем ровно 20 МГц.
- **AMATERASU** — экран 320×240, RGB555, 511 цветов палитры. Слот 511 отбрасывается.
- Одна `cls` за кадр бесплатна. Дальше блиттер считает каждый записанный пиксель.
- **STRIBOG** — 8 каналов. Музыка занимает 0–6, эффекты — 7. Микшер не ест такты процессора.

TPython компилируется в ассемблер THOTH и исполняется этим железом. Это не CPython.

## TPython коротко

Отступы, как в Python. Целые 32 бита со знаком. Списков чисел и строк хватает для игры. Дробей нет: только `//` и `%`.

Каждый кадр консоль зовёт `_update`, потом `_draw`. Один раз в начале — `_init`.

```python
px = 40

def _init():
    music(0)

def _update():
    global px
    if btn(1):
        px = px + 2

def _draw():
    cls(0)
    spr(1, px, 100, 2, 2)
    text("ARGONAUT", 8, 8, 1)
```

Язык, кнопки и рисунок расписаны в [docs/tpython.md](docs/tpython.md).

## Лицензия

MIT. Консоль можно форкать, встраивать и продавать. Игры, которые вы на ней напишете, этой лицензией не связаны: их код ваш.

## Запуск

Нужен Python 3.10+ и pygame.

```bash
pip install -r requirements.txt
python -m argonaut
```

Проверка без окна:

```bash
python -m unittest discover -s tests
python -m argonaut --selftest
```
